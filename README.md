# Calculator App

A feature-rich, responsive web calculator application built with vanilla HTML, CSS, and JavaScript, featuring advanced mathematical operations, memory functions, calculation history, full keyboard support, and dark/light theme toggling.

## Features

- **Standard & Advanced Operations**: Addition, subtraction, multiplication, division, square root, square, negation, and decimals with precision handling.
- **Memory Functions**: Memory Clear (MC), Memory Recall (MR), Memory Add (M+), and Memory Subtract (M-).
- **Calculation History**: Calculation history panel displaying past expressions and results.
- **Keyboard Support**: Fully navigable via keyboard (digits, operators, Enter/Return, Escape, and Backspace).
- **Theme Support**: Seamless dark mode and light mode toggle.
- **No Build Step / Server Required**: Works out of the box when opened directly in any modern web browser.

## How to Run

### Running the Web App
Simply open `index.html` in your web browser:
- Double-click `index.html` in your file explorer, or
- Open it via your browser's File -> Open menu.

### Running Automated Tests
The project includes automated unit tests for the core calculator logic using Node.js built-in test runner (`node --test`).

To run tests:
```bash
npm test
```
